# SomeGame · 逃离撤离点

类**狼人杀 + 三国杀**的多人回合制网页游戏：在格子地图上隐藏身份、搜集情报、查验对手，
用卡牌战斗，围绕"保护/击杀/窃取/清场"展开博弈，最终活着抵达撤离点。

- 后端：C#（.NET 10）权威服务器，WebSocket 实时通信
- 前端：浏览器打开即玩（无需安装）
- 支持：4 人 / 8 人开黑，也可单人 + 机器人完整体验

## 一、快速开始

```bash
dotnet run --project src/SomeGame.Server
```

浏览器打开 `http://localhost:5123`：

1. 点“创建房间”，选择 4 人或 8 人；
2. 朋友在同一局域网访问 `http://<你的IP>:5123`，输入房间号加入；
3. 房主点“开始游戏”，**空位自动由机器人补齐**，单人也能立刻开一局。

> 换端口：`SOMEGAME_PORT=8080 dotnet run --project src/SomeGame.Server`
> 局域网/公网部署见 [docs/deploy-remote-linux.md](docs/deploy-remote-linux.md)。

## 二、玩法介绍

### 身份与目标（本局随机分配，互相隐藏）

| 身份 | 目标 | HP |
| --- | --- | --- |
| 保镖 | 守护指定“贵宾”及其财物：贵宾**存活抵达撤离点**且财物未被窃取 | 5 |
| 杀手 | 击杀指定贵宾，随后**本人活着抵达撤离点**核验 | 3 |
| 小偷 | 窃取指定贵宾的财物，随后**携物活着抵达撤离点**核验 | 2 |
| 疯子 | **清场**：击杀本局所有保镖、杀手、小偷 | 4 |

开局有大量普通 NPC 混在人群中，所有人身份不明，需要从行动记录中推断。

### 回合流程

每回合包含两个阶段，直到有人达成目标或回合上限：

1. **自由行动阶段**（每人 3 行动点）
   移动、探查、翻箱找卡、交谈、治疗、布置陷阱、窃取……
2. **身份查验阶段**（按座位依次进行）
   选择一名角色查验其身份；若对方是敌对身份且在交战范围内，
   可以**发起战斗**——双方用手牌轮流攻防，直到一方倒下、双双无牌或有人烟雾弹撤退。

### 地图与情报

- 格子地图上的**情报随距离衰减**：同格看得最清楚，相邻格只知道谁做了什么，
  更远只能知道“有人”在活动；受保护贵宾开局不会盲目冲向撤离点——身份未暴露时只在附近徘徊，第 5 回合起撤离点对保镖开放，可被保镖“催促移动”，暴露后才会确定向撤离点推进。
- 开箱可获得**技能卡**（初始每人 5 张，其余散落地图），用过的卡会进入回收池并按期重新投放。

### 技能卡一览（一期 21 种）

攻击/防御：枪械攻击、刀械攻击、闪避、防暴盾、兴奋剂、瞄准狙击、快速连射
情报/功能：隐身、窃听器、治疗包、能量饮料、无人机探查、弹药包、管制刀具、染色球、燃烧瓶、烟雾弹、万能胶
身份对抗：身份伪装、行动模仿、追踪探查

### 胜负判定

**事件触发式结算**（可多人同胜）：
- 贵宾存活抵达撤离点且财物完好 → 保镖胜
- 小偷携财物抵达撤离点 → 小偷胜
- 指定贵宾死亡且杀手撤离核验 → 杀手胜
- 疯子清场 → 疯子胜
- 回合上限 → 未分胜负
